# Security and responsible use

`cas+` is intended for offline/demo use and controlled local testing only.

- No anti-cheat bypass is provided or supported.
- Do not use the injector on protected, competitive, or third-party systems without authorization.
- Do not report ordinary incompatibility after a CS2 update as a security vulnerability.
- For an actual vulnerability in this private repository, contact the repository owner privately and avoid publishing exploit details.
