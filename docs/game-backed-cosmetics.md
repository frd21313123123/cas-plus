# Game-backed cosmetics catalog

`cas+` now builds its cosmetic catalog from the user's installed CS2 immediately before the payload is injected.

The loader reads the installed `csgo/pak01_dir.vpk`/loose game files, parses `scripts/items/items_game.txt`, resolves localized names from the installed game resource file, and derives weapon/paint compatibility from `alternate_icons2`. It records the real item definition, paint kit, localized weapon/finish names, Panorama icon resource path, and player/world model paths.

Records are deduplicated by `(item definition, paint kit)`. The payload rejects arbitrary raw paint IDs when the game catalog is available and sanitizes obsolete stored combinations that no longer exist in the current installed game.

The generated snapshot is versioned and checksummed at `%TEMP%/cas_plus_game_catalog_v1.bin`; it is regenerated by the loader before injection so game updates do not require maintaining a separate hand-written skin list.

The current GDI menu consumes game-backed names and compatibility data. `iconResource` is the exact game Panorama/compiled-resource path and is retained for the thumbnail renderer; Source 2 `.vtex_c` pixel decoding/rendering is a separate UI layer.
